# LZ KINET · Suite Clínica Kinesiológica

Sistema clínico completo para kinesiólogos y fisioterapeutas, en **un solo archivo HTML**. Funciona en **iPhone, Android y PC** sin instalar nada.

## ✨ Funcionalidades

- **HC digital** con anamnesis estructurada en 6 pasos (motivo, historia, antecedentes, medicación, evaluación, dx/objetivos)
- **~120 patologías** con código CIE-10: desde desgarros y fracturas hasta patologías complejas y raras (CRPS, osteogénesis imperfecta, distrofia de Steinert, VPPB, post-COVID, etc.)
- **Farmacología inteligente**: 42 fármacos con contraindicaciones cruzadas fármaco↔patología, interacciones y precauciones de sesión
- **Sesiones estructuradas 40–60 min**: generador por fases con presupuesto de minutos, cronómetro con beep y registro EVA pre/post
- **Progresiones de ejercicios**: 4 fases (adaptación → carga → fuerza → retorno) con dosis por sesión
- **Adherencia del paciente**: check-in diario, racha, % de cumplimiento a 30 días, logros y gráfico dual adherencia-EVA
- **Goniometría digital** (IMU en teléfonos, modo manual en PC) y **análisis postural**
- **Exportación**: WhatsApp, CSV y respaldo JSON
- **Multiplataforma**: safe-area iOS, permisos `DeviceOrientationEvent`, botones táctiles ≥44px

## 🚀 Cómo usarla

1. Abrí el link de GitHub Pages (o descargá `index.html` y abrilo con doble clic).
2. En iPhone: **Compartir → Añadir a pantalla de inicio** y queda como app.
3. En PC: guardá la URL en favoritos.

## 🔒 Privacidad

Los datos de pacientes se guardan **solo en tu dispositivo** (localStorage). Este repositorio no contiene ni transmite información clínica. Incluye 3 pacientes de demostración con datos ficticios.

## ⚠️ Aviso

Herramienta de apoyo clínico para profesionales matriculados. No reemplaza el juicio profesional ni el diagnóstico médico.
